# `renderer/features/sounds/`

Notification sounds.

The short tones the bell can play, synthesised rather than shipped as files,
plus the Piper TTS hand-off for the spoken "done".

## Files

`sounds.js`

## Public interface

`Sounds.OPTIONS`, `.play(name)`, `.speak(text)`. A classic script.

## How to test

**Options → Notifications**, pick each sound — the picker previews it.
